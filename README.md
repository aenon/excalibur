# Excalibur

A mobile-first web app for **The Resistance: Avalon** that handles role assignment so you can focus on the game.

## What It Does

- **Sign in with Google** and set a display name
- **Create or join a game room** using a short room code or the room list
- **Host configures roles** — pick exactly which roles are in play and how teams are split
- **Tap to reveal** — each player privately sees their assigned role on their own phone
- **Post-game review** — after the game, see who was who

Built for groups of 5–10 players who are physically together (or on a video call) and want a quick, clean way to deal roles without fumbling with cards.
